AstroTable is a lightweight authoring system that converts Markdown (GFM tables) into Astro components at build time. The first cell of a table's header row becomes the component name, so you can assemble a page without writing any code.

If you're seeing this page, AstroTable is running correctly. Check out the links below to see it in action.
