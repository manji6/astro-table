## AstroTable v0.2.0

v0.1.0 以降に本体へ取り込まれた機能追加をまとめたリリースです。この版から、バージョン番号による管理を運用として回し始めます。npmパッケージの公開は行いません。

### 含まれる機能

- hero Block に `lead` キーを追加（#27）
- cards Block に説明文（第4列）を追加（#28）
- table Block に header variant（見出し行）を追加（#29）
- `member.enabled` の既定値について README に明記（#30）
- バージョン番号による管理をこの版から運用として開始（#37）

### 破壊的な変更・移行手順

なし。既存の記法や設定はそのまま動作します。table の見出し行は、variant を指定したときだけ有効になる追加機能です。

### バージョン運用

引き続きSemVer形式の `vMAJOR.MINOR.PATCH` を使います。0.xでは機能追加と破壊的な変更をマイナー更新、互換性のある修正をパッチ更新として公開します。公開済みタグは付け替えません。
